# Pragmr OnTime — Marketing Site PRD

## Original Problem Statement
Build a marketing experience for "Pragmr OnTime" from a 2-page content spec (Page 1: Product Overview + Core Features; Page 2: Outcomes + Intelligence). User chose: one long scrolling page per theme, follow pragmr.com branding aesthetics (light paper, ink, hairline grids, Cabinet Grotesk, brand #514EB3), CTAs open a Book-a-Demo email capture. Later simplified to a clean 2-page site. Brand architecture: Pragmr™ is the trademark-certified master brand; OnTime is the product name.

## Architecture
- React (CRA + craco) frontend (port 3000) + FastAPI backend (port 8001) + MongoDB.
- `POST /api/demo-requests` — email capture (collection `demo_requests`: {id, email, created_at}); `GET /api/demo-requests` lists them.
- React Router: `/` (Home: Hero + outcomes card + features) and `/intelligence` (dark-ink presentation). `framer-motion` reveals, lenis smooth scroll, paper grain overlay.
- Design tokens: paper #F4F4F2, ink #131316, line #E4E4E7, brand #514EB3 (+dark/light/pale), delay #F59E0B, ontrack #10B981, critical #EF4444. Fonts: Cabinet Grotesk (display), General Sans (body), JetBrains Mono (labels).

## Logo System (v11, FINAL — session 2026-10-01)
Unique product identity built from the authentic brand, per user's explicit choices:
- **Lockup**: `[authentic pragmr.com wordmark — P-arrow icon + "ragmr" + ™, indigo #514EB3, used AS-IS]` + **growth separator** (rising trend line with arrival node — denotes growth, one stroke + one dot, easy to hand-draw) + `⊙nTime` — the **O of OnTime is the brand ring-tick mark** (round-capped ring, gap at top-right, check tick inside; arrival node doesn't fit at letter size).
- Implementation: `Logo.jsx` renders inline SVG — authentic paths from `components/pragmr-mark.js` (AUTH_TRANSFORM/AUTH_PATHS parsed from public/pragmr-logo.svg, viewBox 134 115 459 112, baseline y=199, scaled so auth ink height = 26 units, baseline aligned to 30.53) + geometry from `components/wordmark.js` (TREND_D, TREND_DOT, O_ARC_D, O_TICK_D, NTIME_D, TOTAL_RIGHT — outlined Cabinet Grotesk 800 paths, generated via fontTools, NO font/img dependency).
- Animated hero variant: authentic wordmark fades in → trend line draws → node pops → ticked-O ring draws → nTime fades → tick draws last.
- Variants: light (indigo OnTime part) / dark footer (brand-light #A8A6E8 + trend line in translucent paper). Footer has `bg-ink` (dark surface — REQUIRED for dark variant legibility).
- PNG kit regenerated by `/tmp/gen_logo_kit.py` (Cabinet Grotesk 800 TTF from Fontshare + fonttools): ontime-logo.png, ontime-logo-dark.png, ontime-icon.png, favicon.png, favicon.svg, apple-touch-icon.png, og-image.png. Favicon/app icons = standalone ring-tick mark on brand tile; OG = lockup + rule + tagline on paper 1200×630.
- Logo variants history: v9 unique ring-tick mark + outlined "Pragmr™ | OnTime" → v10 ticked-O replacing the O → v11 (current) authentic Pragmr wordmark + growth separator + ticked-O. Jira-style diamond concepts were rendered as previews and NOT chosen.
